# Tracko (Habit Tracker Frontend)

Tracko is a habit-tracking frontend built with Next.js. It helps users create habits, track daily progress with a slider, and see completion stats at a glance.

## Functionality
- Sign up and login with email/password or Google
- Email verification flow after signup
- Forgot password flow with reset link and new password setup
- Create habits with goals and units
- Add habits to specific dates for tracking
- Update progress via slider or mark complete with one tap
- View daily totals, completion rate, and completed count
- Light/dark mode support

## Features
- Email/password auth and Google login
- Create, edit, and delete habits
- Add habits to a date and update progress with a slider
- Completion stats and streak-friendly dashboard UI
- Light and dark mode styling

## Tech Stack
- Next.js (Pages Router)
- React, Redux Toolkit
- Tailwind CSS

## Getting Started
```bash
npm install
npm run dev
```

## Environment
Create a `.env` file and set:
- `NEXT_PUBLIC_APP_API_BASE_URL`
- `NEXT_PUBLIC_GOOGLE_CLIENT_ID`
